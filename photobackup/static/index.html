Working…

1. Folders

Copy the iPhone's DCIM folder to the PC first (File Explorer → Apple iPhone → Internal Storage), or use the folder that iCloud for Windows / the Windows Photos app imports into.

2. Options

After backing up
Saved ✓

3. Run

Preview first: nothing is copied until you press Start backup. Existing files are never overwritten — identical files are skipped, different files with the same name get “ (1)”.

Choose a folder

“Exact” = byte-for-byte identical. “Similar” = looks alike (bursts, re-saves, edits) — review carefully. The suggested copy to keep is marked KEEP; the others are pre-selected. Click a photo to view it.

Worst (blurriest) first. Nothing is selected automatically — tick the ones you want to delete. Sharpness score: lower = blurrier.
